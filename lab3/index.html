Lab 3 — Web Data Acquisition with Python

The table below shows a dataset I acquired programmatically with a Python script. Click any column heading to sort the table (click again to reverse the direction).

Dataset
Top cryptocurrencies by market capitalization, including price, market cap, 24-hour trading volume, and 24-hour price change.
Source
CoinGecko public API — coingecko.com (free, no API key required).
Acquisition method
REST API using Python requests (parsed as JSON). The script pages through the /coins/markets endpoint (250 records per request), with a delay between requests (rate limiting) and try/except error handling.
Records collected
1,000 cryptocurrencies
Responsible acquisition
CoinGecko provides a public API intended for programmatic access. The script identifies itself with a User-Agent, requests only the data needed (four paginated calls), and pauses between requests to avoid excessive load. No authentication, paywalls, or restrictions were bypassed, and no private personal data was collected.
